# 芭蕾舞女鬼 · 黑房间

一款第一人称生存恐怖小游戏。房间完全漆黑，只能看见五个白色假人。聚光灯亮起时，女鬼附身在其中一个假人身上，跳着舞向你逼近。

你要一直正视聚光灯下的假人，后退、绕圈，活到天亮。

## 玩法

- 五个白色假人站在黑房间里，其中一个头顶有聚光灯柱。
- 被附身的假人一边跳舞，一边持续朝玩家靠近。
- 玩家必须把视线保持在它身上；移开视线约 2 秒会立即死亡。
- 假人贴到玩家约 1 米内，也会立即死亡。
- 每隔一段时间，聚光灯会随机跳到另一个假人身上，玩家要立刻重新锁定。
- 坚持 **75 秒** 即通关。
- 每 15 秒进入下一阶段：换人间隔从约 12 秒缩短到 3 秒，假人速度从 0.82 提升到 2.25。

没有手电，没有护身符，没有第二次机会。

## 运行

直接双击根目录的 `index.html`，用支持 Canvas 2D 和 WebAudio 的现代浏览器打开即可。游戏是单文件、完全离线、无外部素材依赖。

手机建议使用横屏或全屏；触摸操作：左半屏虚拟摇杆，右半屏拖动视角，右下角冲刺。

## 开发与构建

源码在 `src/`：

| 文件 | 内容 |
| --- | --- |
| `src/index.html` | 页面结构 |
| `src/style.css` | 界面与后期效果 |
| `src/audio.js` | WebAudio 程序化音效 |
| `src/art.js` | 程序化贴图、假人、女鬼动画 |
| `src/engine.js` | 光线投射、输入、状态机、AI、UI |

修改源码后，在 Windows PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本会把 CSS / JS 内联回根目录的 `index.html`（单文件构建版）。

## 部署成永久公网链接

当前仓库已经包含可直接托管的根目录 `index.html`。

### GitHub Pages

1. 新建一个 GitHub 仓库（Public）。
2. 把本文件夹里的全部文件上传到仓库根目录（保持 `index.html` 在根目录）。
3. 进入仓库 **Settings → Pages**。
4. **Build and deployment** 选择 **Deploy from a branch**。
5. 分支选 `main`，目录选 `/ (root)`，保存。
6. 一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

这个地址是永久的，别人在任何网络都能打开，同时源码也是公开的。

### Netlify Drop

也可以把整个文件夹拖到 https://app.netlify.com/drop ，得到一个 `https://xxxx.netlify.app` 地址。

## 技术

- Canvas 2D 光线投射（raycasting），自建深度缓冲与精灵遮挡。
- 程序化墙面、地面、白色裂纹假人、女鬼多帧动画、聚光灯柱与尘埃。
- WebAudio 合成八音盒、心跳、足尖声、低语、玻璃声与尖叫。
- 移动端触摸摇杆 / 视角拖动、自适应分辨率、画质与亮度设置。
- 无任何 CDN、图片、音频或第三方运行时依赖。

## 图片与音频素材

全部由代码在运行时绘制/合成，不使用第三方素材。你可以自由替换为自己的美术与音效。
